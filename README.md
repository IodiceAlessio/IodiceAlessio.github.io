# Welcome to my portfolio

## Introduction

This is my personal portfolio, built with Astro.

:sparkles: It tells you who I am, with a backend / distributed systems angle: experience, projects, skills.

:page_facing_up: It generates an ATS-friendly PDF resume straight from the same data that powers the site.

:rocket: A GitHub Actions workflow builds and deploys it to GitHub Pages on every push to `main`.

Visit me @ [IodiceAlessio.github.io](https://IodiceAlessio.github.io/)

## Technologies Used

- [Astro](https://astro.build/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [pnpm](https://pnpm.io/)
